[VERBATIM — Durée de vie]
We depreciate these assets on a straight-line basis using estimated useful lives of 30 years for buildings and two to seven years for furniture, equipment and software development costs.

[VERBATIM — Segments (Task 6)]
Software Development Costs and Cloud Computing Arrangements ||| In evaluating whether our cloud computing arrangements include a software license, we consider whether we have the contractual right to take possession of the software at any time during the hosting period without significant penalty and whether it is feasible for us to either run the software on our own hardware or contract with another party unrelated to the vendor to host the software. If a cloud computing arrangement includes a software license, we account for the software license element of the arrangement consistent with the acquisition of other software licenses. If a cloud computing arrangement does not include a software license, we account for the arrangement as a service contract.
