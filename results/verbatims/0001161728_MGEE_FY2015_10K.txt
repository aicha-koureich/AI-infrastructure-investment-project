Cloud Computing Arrangements. ||| In April 2015, the FASB issued authoritative guidance within the Codification's Software topic that provides guidance on the accounting treatment of cloud computer arrangements. This authoritative guidance is effective January 1, 2016. The authoritative guidance provides criteria for determining whether a cloud computing arrangement contains a software license that should be accounted for as internal-use software. The impact of this guidance on our financial statements is not expected to be material.
