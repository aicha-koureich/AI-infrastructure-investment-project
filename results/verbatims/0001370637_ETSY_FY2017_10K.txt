[VERBATIM — Segments (Task 6)]
If a cloud computing arrangement includes a software license, then the Company accounts for the software license element of the arrangement consistent with the acquisition of other software licenses. If a cloud computing arrangement does not include a software license, the Company accounts for the arrangement as a service contract.
