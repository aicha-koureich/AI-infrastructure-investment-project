Intangibles—Goodwill and Other—Internal-Use Software (Subtopic 350-40): Customer's Accounting for Fees Paid in a Cloud Computing Arrangement ||| . ASU 2015-5 provides guidance regarding whether a cloud computing arrangement includes a software license. If a cloud computing arrangement includes a software license, the software license element of the arrangement must be accounted for in a manner consistent with the acquisition of other software licenses. If a cloud computing arrangement does not include a software license, the arrangement must be accounted for as a service contract. ASU 2015-5 does not change the accounting for service contracts. ASU 2015-5 is effective for fiscal years, including interim periods within those fiscal years, beginning after December 15, 2015.
