ASU 2018-15, “Intangibles - Goodwill and Other - Internal-Use Software (Subtopic 350-40) - Customer’s Accounting for Implementation Costs Incurred in a Cloud Computing Arrangement That Is a Service Contract.” ASU 2018-15 clarifies certain aspects of ASU 2015-05, “Customer’s Accounting for Fees Paid in a Cloud Computing Arrangement,” which was issued in April 2015. Specifically, ASU 2018-15 aligns the requirements for capitalizing implementation costs incurred in a hosting arrangement that is a service contract with the requirements for capitalizing implementation costs incurred to develop or obtain internal-use software (and hosting arrangements that include an internal-use software license). ASU 2018-15 does not affect the accounting for the service element of a hosting arrangement that is a service contract. ASU 2018-15 will be effective for us on January 1, 2020.
