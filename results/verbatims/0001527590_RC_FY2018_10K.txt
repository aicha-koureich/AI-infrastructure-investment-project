ASU 2018-15, Intangibles - Goodwill and Other - Internal-Use Software (Subtopic 350-40): Customer’s Accounting for Implementation Costs Incurred in a Cloud Computing Arrangement That Is a Service Contract ||| Provides guidance on evaluating the accounting for fees paid by a customer in a cloud computing arrangement (hosting arrangement) by providing guidance for determining when the arrangement includes a software license. ||| An intangible asset is recognized for the software license and, to the extent that the payments attributable to the software license are made over time, a liability also is recognized. If a cloud computing arrangement does not include a software license, the entity should account for the arrangement as a service contract. This generally means that the fees associated with the hosting element (service) of the arrangement are expensed as incurred.
